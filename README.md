# CDS 리소스 사이트

HTML, CSS, JavaScript만 사용하는 정적 사이트입니다. 설치나 빌드가 필요 없습니다.

## 파일 구조

모든 파일을 저장소 최상위 폴더에 나란히 놓습니다.

- index.html: 페이지 구조와 더 찾아보기 사이트 목록
- style.css: 디자인과 모바일 배치
- resources.js: 추천 자격증·학습 과정 및 데이터셋 데이터
- app.js: 검색, 필터, 상세 보기 동작
- README.md: 사용 안내

## 실행

index.html을 브라우저로 열면 됩니다.

## 함께 수정할 부분

- 온오프믹스 등 탐색 사이트: index.html의 directory-group / directory-link
- 추천 자료 제목·설명·링크·확인일: resources.js의 records
- 색상·배치: style.css
- 검색·상세 보기: app.js

resources.js에는 전문 자격시험 외에 수료증과 디지털 배지도 포함되어 있습니다. 각 항목의 유형을 구분해 유지하세요. 신규 개별 기회는 공식 정보와 자격·일정을 확인한 뒤 추가하세요. 값을 수정할 때 따옴표와 쉼표를 유지하세요.
